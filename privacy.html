Privacy Policy – MightyOwl Shorts

Last updated: October 12, 2026

What the app does

MightyOwl Shorts uploads videos produced by its operator to the operator's own YouTube channels. It can also send them as drafts to the operator's own TikTok accounts. The only user of the app is the channel owner.

Google user data the app accesses

  • YouTube upload permission (youtube.upload): used only to upload videos to the signed-in channel.
  • Read-only channel information (youtube.readonly): used only to show the name of the connected channel.

TikTok user data the app accesses

  • Basic profile information (user.info.basic): used only to confirm which account is connected.
  • Video upload permission (video.upload): used only to send videos as drafts to the connected account's inbox; the owner publishes them manually in the TikTok app.

Storage and sharing

The sign-in token is stored only on the operator's own computer and is never sent anywhere except to Google's APIs. No Google user data is sold, shared with third parties, or used for advertising.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
